# Exemplos sanitizados

Este diretório receberá exemplos portáteis que não reproduzem a configuração de produção.

Todos os exemplos devem:

- usar nomes e endereços fictícios
- omitir credenciais reais
- usar placeholders descritivos
- evitar dados pessoais e identificadores
- passar pela varredura de segredos
- informar o que precisa ser adaptado antes do uso

Nenhum arquivo `.env` será publicado.
