# Hermes Agent

O Hermes Agent representa a camada de consulta e interpretação da plataforma.

## Regra de evidência

O agente deve consultar fontes reais e autorizadas antes de responder sobre disponibilidade, incidentes, métricas ou backups. Ausência de dados deve resultar em uma resposta explícita, não em inferência.

## Estado atual

A base do agente e a interação por Telegram estão implantadas. A integração completa com a API do Zabbix e os alertas inteligentes permanecem no roadmap.

Este diretório não contém tokens, sessões, memórias, arquivos de perfil ou configuração operacional do agente.
