# Backup centralizado

Esta etapa permanece em planejamento.

A arquitetura candidata usa estações Windows, UrBackup e um HD externo conectado ao servidor. O desenho deve definir retenção, capacidade, criptografia, restauração e monitoramento antes da implantação.

Critérios de conclusão:

- política de retenção aprovada
- destino de backup dimensionado
- restauração de arquivo validada
- restauração completa testada
- estado do backup monitorado pelo Zabbix
- alertas entregues pelo Hermes Agent e Telegram
