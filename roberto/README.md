# Roberto

Roberto é a camada de interpretação e comunicação operacional baseada em Hermes Agent.

## Funções

- resumir estado da infraestrutura;
- comunicar alertas críticos;
- consumir inventário estruturado;
- reduzir ruído operacional com relatórios curtos.

O repositório não inclui tokens de Telegram, sessões, bancos Hermes ou configuração privada.
