# Inventário

O inventário estruturado é a fonte de verdade para os ativos documentados. Roberto apenas consome e interpreta esse inventário.

## Classes de ativo

- `ATIVO_FISICO`
- `ATIVO_FISICO_PROVAVEL`
- `ATIVO_LOGICO`
- `INTERFACE_BSSID`
- `ATIVO_NAO_IDENTIFICADO`

## Confiança

- `CONFIRMADO`: evidência física ou técnica inequívoca.
- `PROVÁVEL`: inferência razoável, mas ainda sem confirmação suficiente.
- `NÃO IDENTIFICADO`: informação insuficiente.

OUI de MAC sozinho não confirma modelo. Porta aberta sozinha não confirma tipo de equipamento.

## Dados privados

Seriais, patrimônios, usuários, fotos, IPs/MACs reais e localização detalhada permanecem fora da versão pública.
