# Publicação no site RSFBINFORMATICA

O projeto será apresentado na área **Projetos** sem credenciais, endereços internos ou detalhes que permitam acesso ao ambiente.

## Card proposto

- **Nome**: NEPEAC Infrastructure Monitoring
- **Descrição**: Plataforma open-source para monitoramento, observabilidade, disponibilidade e gerenciamento remoto da infraestrutura.
- **Principais tecnologias**: Zabbix, Grafana, Uptime Kuma, MeshCentral, Tailscale, Hermes Agent e Telegram
- **Visibilidade aprovada**: pública
- **Ação**: Abrir no GitHub

## Regra para projetos privados

Cards privados não devem gerar links para o GitHub. O site deve exibir apenas a mensagem de indisponibilidade. Essa regra evita links sem acesso e deixa claro que a restrição é intencional.

A alteração está preparada fora da produção. Ela depende de aprovação, cópia de segurança do tema, análise estática do código PHP, implantação controlada e validação visual em desktop e celular.
