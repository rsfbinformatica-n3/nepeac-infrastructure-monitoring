# Plano de conteúdo

## Visão geral

Este projeto documenta uma plataforma open-source de monitoramento e gerenciamento para a infraestrutura do NEPEAC.

## Objetivo

Explicar a arquitetura implantada, registrar o estado real dos componentes e orientar a evolução segura do ambiente.

## Público

- administradores de infraestrutura
- profissionais de suporte e observabilidade
- equipes que avaliam uma arquitetura open-source semelhante

## Conteúdo

- arquitetura e responsabilidades dos componentes
- limites de segurança da publicação
- operação sanitizada por tecnologia
- roadmap de monitoramento e backup

## Questões em aberto

- política final de retenção dos backups
- modelo e capacidade do HD externo
- desenho da integração entre a API do Zabbix e o Hermes Agent
- estratégia de testes automatizados de restauração
